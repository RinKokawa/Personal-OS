# Personal OS 工作计划

> **[ NEXT OBJECTIVE: BUILD THE SYSTEM ]**
>
> 本计划依据新版 `README.md` 制定。当前目标不是先堆 UI，而是建立一套可以逐步成长的本地个人系统骨架。

## 0. 开发原则

1. **实用优先**：每个功能必须解决真实问题。
2. **可控优先**：本地数据、外部请求、Agent 操作必须有明确权限边界。
3. **可成长优先**：先做最小可用闭环，再逐步解锁能力。
4. **文档先行**：核心概念、数据模型、权限规则先写清楚，再实现界面。
5. **Local First**：宿主数据默认保存在本地，云模型和外发数据必须可识别、可授权。

## 1. 模块命名与产品概念

新版概念体系如下：

| 系统模块  | 原功能方向           | 说明                                   |
| --------- | -------------------- | -------------------------------------- |
| STATUS    | Dashboard / Profile  | 宿主状态、系统状态、统计与总览         |
| QUEST     | Todo / Planner       | 主线任务、支线任务、每日任务、动态任务 |
| JOURNAL   | Journal              | Markdown 系统日志、时间轴、回顾与检索  |
| SKILLS    | Skills               | 技能图谱、学习记录、成果追踪           |
| INVENTORY | Projects / Resources | 项目、文件、仓库、工具、资源索引       |
| ABILITIES | Toolbox / Automation | 工具、脚本、自动化、AI 能力模块        |
| AGENT     | Agent Hub            | Pi 接入、会话、日志、审批、权限        |
| SYSTEM    | Settings / Core      | 本地数据、配置、权限、备份、恢复       |
